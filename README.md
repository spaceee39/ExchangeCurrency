# 💱 Проект «Обмен валют»

## Что это и для чего?

Проект представляет собой реализацию **REST API для обмена валют**, написанную по ТЗ из роадмапа Сергея Жукова.

API позволяет просматривать и изменять информацию о валютах и курсах обмена, а также производить обмен по курсам.

Проект ставит перед собой цель отработать понимание того, как разрабатываются приложения с архитектурой **MVC**. Он даёт опыт в проектировании бэкенд-систем по определённым архитектурным стилям, а также учит работе с HTTP и помогает понять, как он устроен.

### Чему ещё можно научиться

- Настройка слоя конфигурации приложения
- Настройка контекста приложения
- Разработка слоистой архитектуры и правильное выстраивание взаимодействия между слоями
- Организация пула соединений

## 📡 API

**Базовый URL:** `http://<server-api>/api`

### Валюты

| Метод | Путь | Описание |
|-------|------|----------|
| `GET` | `/currencies` | Получить список валют |
| `GET` | `/currency/{CODE}` | Получить определённую валюту |
| `POST` | `/currencies` | Добавить валюту |

**`POST /currencies`** — формат полей `x-www-form-urlencoded`:

| Поле | Ограничения |
|------|-------------|
| `name` | Длина не более 30 символов |
| `code` | 3 символа из A-Z |
| `sign` | Не более 5 символов |

### Курсы обмена

| Метод | Путь | Описание |
|-------|------|----------|
| `GET` | `/exchangeRates` | Получить список курсов обмена |
| `GET` | `/exchangeRate/{BASE_CURRENCY_CODE}{TARGET_CURRENCY_CODE}` | Получить определённый курс обмена |
| `POST` | `/exchangeRates` | Добавить курс обмена |
| `PATCH` | `/exchangeRate/{BASE_CURRENCY_CODE}{TARGET_CURRENCY_CODE}` | Обновить курс обмена |

**`POST /exchangeRates`** — формат полей `x-www-form-urlencoded`:

| Поле | Ограничения |
|------|-------------|
| `baseCurrencyCode` | 3 символа из A-Z |
| `targetCurrencyCode` | 3 символа из A-Z |
| `rate` | Курс обмена |

**`PATCH /exchangeRate/{BASE_CURRENCY_CODE}{TARGET_CURRENCY_CODE}`** — формат полей `x-www-form-urlencoded`:

| Поле | Описание |
|------|----------|
| `rate` | Новое значение курса |

### Обмен валют

| Метод | Путь | Описание |
|-------|------|----------|
| `GET` | `/exchange?from={BASE_CURRENCY_CODE}&to={TARGET_CURRENCY_CODE}&amount={AMOUNT}` | Выполнить обмен указанной суммы по курсу |

**Пример:**

```http
GET /api/exchange?from=USD&to=EUR&amount=100
```
